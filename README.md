# misis2026_PA_16_baranov

Программирование и алгоритмизация  группа БИВТ-16 Баранов.

## Структура

| Папка | Содержимое |
|---|---|
| `docs/` | Условия лабораторных работ |
| `labs/lab1/` | Лабораторная 1. Функции |
| `labs/lab2/` | Лабораторная 2. Многофайловая компоновка. Тестирование |
| `labs/lab3/` | Лабораторная 3. Типы данных и операции над ними |
| `labs/lab4/` | Лабораторная 4. Обработка ошибок. Рекурсивные функции |
| `Test/Test1/` | Контрольная работа 1 |

В каждой лабораторной:

- `header.h` — прототипы функций;
- `source.cpp` — реализация;
- `main.cpp` — демонстрация работы функций, в том числе на крайних случаях;
- `tests/tests.cpp` — модульные тесты (Microsoft C++ Unit Test Framework), начиная со второй лабораторной.
